# Population-based Brain Templates for Ultra-Low-Field MRI

Official repository accompanying the Scientific Data publication.

## Publication

Islam KT, Zakavi P, Zhong S, et al.

Population-based Brain Templates for Ultra-Low-Field MRI.

Scientific Data (2026)

DOI:
https://doi.org/10.1038/s41597-026-07622-4

## Resources

This repository provides

- 64 mT population templates
- Brain masks
- Tissue probability maps
- Anatomical atlases
- Regional volumetric statistics
